# РГР з ООП (Завдання 3) — Переглядач і редактор TSV-таблиць

Десктопний застосунок на **Electron** і **TypeScript** для перегляду, сортування та редагування текстових таблиць із розділювачем табуляції (`TSV` / `.txt`).

## Основні можливості

- **Робота з файлами (`.txt`, `.tsv`):** відкриття (`Ctrl+O`), створення нової таблиці (`Ctrl+N`), збереження (`Ctrl+S`) і збереження як; попередження про незбережені зміни.
- **Підтримка кодувань:** автоматичне розпізнавання **UTF-8** (зі зняттям BOM) із резервним переходом на **Windows-1251** при читанні та запис у **UTF-8**.
- **Редагування таблиці:**
  - додавання рядків (`Ctrl+Enter`) і видалення вибраного рядка (`Delete`) з автоматичною перенумерацією;
  - додавання та перейменування стовпців;
  - редагування комірок і заголовків подвійним кліком.
- **Сортування:** тристанове циклічне сортування правим кліком по заголовку стовпця (за зростанням → за спаданням → без сортування) з природним порівнянням (`Intl.Collator('uk', { numeric: true })`), числовим сортуванням стовпця номерів рядків і збереженням вихідного порядку при експорті.
- **Рядок стану:** відображення кількості рядків, стовпців, поточного сортування та кодування файлу.

## Технології

- TypeScript
- Electron
- esbuild
- oxlint, Prettier
- Node.js Test Runner (`node:test`)

## Структура проєкту

- `src/main/index.ts` — головний процес Electron, меню, діалоги файлів та IPC
- `src/preload/preload.ts` — міст `contextBridge` (`electronAPI`)
- `src/renderer/table_model.ts` — модель таблиці (`TableModel`), сортування та стан змін
- `src/renderer/table_view.ts` — компонент рендерингу й інтерактивного редагування (`TableViewClass`)
- `src/renderer/renderer.ts`, `src/renderer/styles/` — контролер інтерфейсу та стилі
- `src/shared/tsv_codec.ts`, `src/shared/table_types.ts` — парсер/серіалізатор TSV (`TsvCodec`) і спільні типи
- `tests/` — модульні тести для `TableModel` і `TsvCodec`
- `sample_table.txt` — приклад таблиці
- `Звіт_РГР_ІМ-55_Присяжний.pdf` — звіт до розрахунково-графічної роботи

## Встановлення та запуск

```bash
npm install
npm start
```

### Корисні скрипти

- `npm run build` — зібрати `main`, `preload` та `renderer` у `dist/`
- `npm test` — запустити модульні тести
- `npm run typecheck` — перевірити типи TypeScript (`tsc --noEmit`)
- `npm run lint` — перевірити код лінтером (`oxlint`)
- `npm run format:check` — перевірити форматування (`prettier`)
